# 反思资产入口

先运行 `python scripts/experience.py reflection` 看短目录，再按ID读取。案例事实统一保存在[reflections.json](reflections.json)，不要把整份JSON放进每次生产上下文。

[静音视频与具体观察区间](../../examples/reflections/index.html) · [架构及开源方案对照](../../docs/architecture.md) · [真实文件树](../../docs/repository-tree.md)

| 案例 | 状态与关键教训 | 对应经验 |
|---|---|---|
| R01 像素街区 | 用户否决；完整背景、贴纸与推拉不等于主体动画 | E20、E12 |
| R02 价签之外 | 用户已确认就是“裙子”旧失败片；保留艺术素材，不继承审美认可 | E20、E04 |
| R03 帕累托初版 | 没字幕、暗、停滞；组件测试不能扩成默认成片 | E19、E18 |
| R04 队列片 | 参数化削弱原版美术与动作；以视觉修复优先 | E21、E05 |
| R05 Kelly独立测试 | 只迁移字体与运行环境；需要实际镜头和独立复测 | E18、E22 |
| R06 基金清仓纸面版 | 字幕确实修好，仍像PPT；工程迁移不等于动画迁移 | E21、E02 |
| R07 原版泊松 | 方向被喜欢，部分解释动作未实现；按具体问题修，勿全盘否定 | E04、E05、E12 |

历史反馈覆盖：内容薄/AI味/语速快仍慢→E01/E02；跨镜断裂→E05；概念图与实片落差→E04/R07；画风不统一又希望多样→E16；长片未证实→E13；缺字幕/局部QA替全片→E19/R03；动作小、背景替动画→E20/R01/R02；迁移丢效果→E21/R04/R06；代做而未修Skill→E22；配乐取错或过短→E14；技术通过冒充认可→E12。具体字幕/布局/数字修复仍在E06–E11、E15、E17；不复制成第二套规则。

更新时分清用户评价、Agent观察、制作方自述。案例已否决不删除旧片；修复版另记，不能覆盖原判定。R04/R05/R06没有在本库捆绑视频，仅有注明范围的历史观察。预览静音、默认暂停。仅本地敏感参考不进入此集合。

维护命令：`python scripts/build_reflections.py`重建查看页；`python scripts/experience.py validate`检查经验元数据；`python -m unittest discover -s tests -p test_experience.py`检验选路与遗漏。
