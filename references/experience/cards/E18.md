# E18 · 流程齐全，画面仍像逐页演示

**触发：** 只复用字体和渲染器；说“对象贯穿”，实际切换时清空；用静帧代替连续小样；称数值同源但显示数字仍写死。

**先做：** 先用 `start_episode.py` 迁移选定完整工程中的字幕、构图和解释镜头，再按新文章改编。需要特定道具时，`select_visual.py --ready` 与 `production.py component-test` 仅用于隔离取材，不把小样扩成默认成片。数字可用 `source/content.json` 与 `compile` 同源生成。

**验证：** 用 `render.mjs proof` 得到实际编码片、逐帧对象/数值记录和待填动态观察。执行 `production.py check`；缺片、过期输入、跳位或无实际素材会报错。检查通过后仍要审查解释动作是否帮助理解，不能把DOM坐标连续当作优秀剪辑。

**保留与边界：** 不重画整套美术，不为凑复用加入不相关资产。已有工程在隔离目录取得模块后移植。主动硬切允许；声明的剪辑方法必须与画面一致。新入口不接管所有Agent，也不保证审美。

**证据：** `cross-agent-visual-gap`；实际接口与验证范围见[可执行入口](../../executable-production.md)。
