# 视觉资产：选择、复用与验证

本库包含 weilanx 固定提交的原始素材、可检索配方和实际历史渲染。不要一次加载整个上游工程。先按解释任务找组件，再读选中项的配方与代码。

## 三个入口

**先用已接好的素材：** `python scripts/select_visual.py --ready` 返回3套可执行装配入口；`production.py init` 会复制静态依赖、许可、字体并生成真实组件引用。具体命令见[可执行生产入口](executable-production.md)。下方完整目录仍适合按需探索，不能把“看过配方”记录成“使用了素材”。

- [统一展厅](../examples/gallery/index.html)：43个专题页，13个制作风格展示、35个艺术场景、9类解说语法、18组历史制作；包含16个旧HTML整理版。
- [机器目录](../assets/weilanx/catalog.json)：每条给出预览、配方、源码、动作与限制。`python scripts/select_visual.py --query 比较` 可检索；`--kind art` 列艺术场景。
- [来源清单](../assets/weilanx/provenance.json)：固定提交、原路径、每文件SHA256及许可。778个上游已跟踪文件原样导出，未混入本地未跟踪文件。

## 原样保存了什么

`assets/weilanx/upstream/` 保存公开上游工程：8套风格工具包、其余共享角色与画面组件、50余期示例源码、8个工作流、风格配方、预览、测试及字体许可。README的16张本地图像（包括项目图标、13个制作展示、两张总览）均在包内。

原始源码和图像归原作者；保留 MIT / 字体 OFL。上游README所述原声、音乐、真人出镜、实拍及截图缺项依然缺少，不能把“代码完整”写成“每期成片素材完整”。不复制作者未公开的内容。

艺术与解说配方继承自 huashu-art-motion。`assets/weilanx/canvas/` 补入其 MIT 引擎库及 OFL 字体，35个场景仍取自 weilanx 的场景代码。播放器适配只选择一个场景、默认暂停、无音频；没有把这些画面冒充我们的新创作。

## 先选解释动作，再锁风格

| 解释任务 | 首选资产 | 内容必须提供 | 跨镜继承 |
|---|---|---|---|
| 比较与选择 | blackgold / PayoffMatrix | 选项、收益单位、比较条件 | 选项身份与被选单元格 |
| 分支与原因 | blackgold / GoldTree | 原因层级、证据、排除条件 | 节点、证据路径 |
| 传播与空间关系 | lamplight / tactical | 地理或空间、传播顺序、时间单位 | 同一信号与空间参照 |
| 流程、整理、反馈 | warm-desk / editor-room | 输入、处理、结果、反馈条件 | 同一资料对象的前后状态 |
| 文献与证据更新 | gilded / halftone / vox | 来源、年份、数据范围、限制 | 原始证据与推论的对应 |
| 人物与类比 | vector / pixel | 角色目标、动作目的、类比边界 | 同一人物、同一道具 |
| 艺术段落 | 35种Canvas场景 | 这一段承担的解释或情绪任务 | 主体轮廓、动作阶段、下段接点 |

同一项目只锁定一个主风格；其它艺术语言只有承担明确任务才加入。不能靠随机换画风制造节奏。每镜记录：主对象ID、起止状态、解释变化、注意力位置、交接对象、真实旁白时间。

借鉴时，直接复用允许再分发的代码与材质；内容、数值、来源、人物身份、构图密度和时序按新文章重做。README图片是参考预览，不能作为已完成本片美术的证据。

## 如何运行和接入

1. 在仓库或已安装Skill根目录启动静态服务：`python -m http.server 8000 --bind 127.0.0.1`。
2. 浏览器打开 `/examples/gallery/`，选择艺术场景“播放原场景”。不使用`file://`直接打开引擎；字体和场景需要HTTP加载。
3. 逐帧接口为 `window.renderFrame(t)`。等 `window.__ready` 为true再取帧；`__bootFailed` 表示失败，不能交付空白占位画面。单场景默认5秒只是观察窗口，不代表最终镜头必须5秒。
4. Remotion部分在 `assets/weilanx/upstream/` 按其package-lock安装依赖并运行。选择组件后移入自己的工程；组件包不依赖每期私有素材。不要把所有示例一次并入当前工程，也不要用缺失素材的整期直接当成成片。
5. 先做8–13秒连续片段，至少有一个解释动作和两处交接，再扩展。已有`examples/batch-01`证明了三组组件的双内容测试；`examples/chapter-01`提供106秒章节实录。

## 验证和历史记录

[Canvas运行记录](../assets/weilanx/canvas-validation.json)检查每个场景几个时点是否可绘制及画面是否变化。这不等于完整连续审片。移植到新文章后仍需检查字幕、对象关系、事实、构图和实际衔接。

历史展厅的MP4是从本地成片生成的完整时长、最高1280px、CRF24无音轨网页副本；原本地文件保留。它们是研究迭代档案，不是全部通过审美验收的模板；不要将被否决版本选成默认基准。每页保留来源边界，特别是“仅有公众号标题而独立研究”的项目。

运行 `python scripts/audit_gallery.py` 检查本地展厅链接、README图片覆盖、素材哈希与文件数；带`--media`调用ffprobe检查网页预览音轨。检查器不能代替观看。
