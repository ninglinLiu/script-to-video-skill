# 凯撒像素街区

[播放两种画幅、三个连续镜头、第二内容](index.html)。页面默认暂停，无音轨。压缩网页副本用于浏览；原尺寸配音成片保存在本地交付目录。

105.57秒、32镜、同一既有凯撒稿与真实旁白时间线；6张完整背景、人物/前景/钟/账本透明层及地图/路线代码层。3:4主文件2160×2880（内部1080×1440后整数放大）；9:16为1080×1920，重新设置相机、人物、字幕、双账单及地图布局。

运行方法见 [pixel-scene-map.md](../../references/pixel-scene-map.md)。场景资产位于 [assets/pixel-scene-map](../../assets/pixel-scene-map/)，参数范例在 configs/。`scripts/pixel_scene.py prepare` 复制完整本地依赖；`render` 按12秒段缓存；`pixel_inspect.py`检查实际编码字幕及全片覆盖。

验证：两种主片各64条字幕、128个起止编码样本，检查3167帧；第二份24秒/6镜配置从干净目录安装并完成两种画幅。这是制作方的配置迁移，不是其他模型的独立验收。

画风比参考更细密、偏写实；人物目前是有限姿态，部分段落仍有纸卡解释。公开候选页没有原参考截帧、音轨或视频；连续左右对照只保留本地。没有宣布1:1审美通过、自动化覆盖任意文章或稳定跨模型高质量。
