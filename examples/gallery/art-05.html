13_pop · 1962 波普（利希滕斯坦漫画格＋沃霍尔四宫格）

文件：scenes/13_pop.js（约 230 行）。性能：warm 平均 6ms、最大 9ms，首帧≈45ms；确定性通过；lt 0.34→0.46 运动差分 11.6% 像素。片中停留 0.47s（T12 黄闪电网点化转场 0.16s）。

管线

  1. 本戴点 = createPattern，零成本：一个 pitch×pitch 的小 tile 画 4 角 + 中心 5 个圆 = 45° 网格（对角间距 pitch/√2）。墙：pitch 24、r5.6、蓝 #2f5cc8 底白（对角 17px，与原片 FFT 量的 17px 周期一致）；皮肤：pitch 13、r3.3、红 #e2483c 底肤色 #fae0cc；黄地：pitch 14 r2.2 α0.18 隐约印刷点。皮肤用 fillStyle = pattern; fill(path)，比 PAINT.halftone（逐点 getImageData）快两个数量级，而且图案对齐屏幕坐标、不会随角色移动「游泳」。
  2. 底版全缓存 pop_bg：漫画格外框 6px 黑；白踢脚线 754–792（上下 6px 黑线）；黄地 796→990/1003（地平线略斜）；红带；MEANWHILE...（Bangers-400 46px，黄底黑框 5px）；沃霍尔白画框＋窗台蓝线；蓝椅；纸面颗粒。
  3. 所有角色都是「粗黑描边 5px + 平涂」，ink(c, path, fill, lw) 一个函数到底；高光用白色粗短线；阴影用 hatch()：椭圆 clip 内画 10px 间距、3.5px 宽的黑斜线。

母题动画

  • 沃霍尔四格换配色：4 套配色（底/脸/下半脸/眼影/口红），step = floor(lt·11)（≈每 5.5 帧换一次，原片 601、605/606、612 帧换），格 i 用第 (i+step)%4 套。猫脸 = RIG.smooth 的 9 点头型 + 下半脸椭圆 + 右侧黑块（丝网错版的黑影）+ 眼影/口红/鼻/胡须；右上格两道白色玻璃反光。
  • 思考泡泡三点依次闪：原片「点1 612–615、点2 614–617、点3 616–618 帧」→ 每 12 帧一循环，点 k 在 ((f-2k) mod 12) < 4 时亮（r20、上跳 6px），否则 r12。泡泡 = 10 个圆先统一描 11px 黑再统一填白（并集轮廓的最省写法）。
  • WIGGLE WIGGLE 爆炸框抖：30fps 卡点 hash 抖动 ±8px/±6px/±0.03rad；外层白爆炸（14 尖，半径 128/178 带随机）+ 内层黄爆炸 + 两行 Bangers-400 82px 红字（12px 黑描边 + 4px 黑投影）；外围 10 根黑三角动作线长度 0.85+0.25·sin(40lt+2i) 脉动。
  • 猫扭屁股准备扑：用 RIG.cat 的锚点做时代化变形——趴低：身体用 10 点自定轮廓（以 K.box 为原点），头 K.headC + (22,104) 压低贴身，前爪白椭圆往前伸；扭：wig = sin(lt·2π·6)·16（6Hz，0.47s 里 ~3 次），点的权重 clamp((560-x)/140) → 越靠屁股位移越大，并同时上翘 |wig|·0.6；条纹、尾巴跟同一变形走；屁股旁三道弧形动作线跟着 wig 移动。
  • 少女端杯：RIG IK 端杯；杯 = 白杯 + 蓝斜条纹 + 咖啡；热气两条 14Hz 抖动的黑波浪线。

少女（利希滕斯坦）

  • 金色大波浪：发团（19 点 smooth，后缘 sin(2.1i+4t)·14 鼓包）＋ 7 个卷团圆（r30–48，沿后缘排），先全部描 10px 黑、再全部填黄 = 并集轮廓；每个卷团里一道 4.5px 黑 C 形弧 + 一道深金 #d9a514 弧 = 利希滕斯坦那种雕塑感卷发；5 条黑色 S 发丝、2 道白高光。
  • 皮肤（脸、颈、手、腿）全部红本戴点；红裙（截到膝，裙摆 clip 用曲线不是矩形）+ 白高光条；两条点点腿 + 红高跟（7 点多边形）；大眼（白眼 12×8.5、蓝虹膜 r7、高光点）+ 3 根粗睫毛 + 眉毛上移 5px；红唇放大。

色板

黑 #141414；纸 #f3eedb；蓝 #2f5cc8；黄 #f7d52c；红 #d8232a/#a8161c；白 #fbf8ee；皮 #fae0cc + 点 #e2483c；金发 #f8d62c/#d9a514；猫 #f39a2c/#c4561a；沃霍尔底色 #9ccf3a/#e0359a/#2fc0b0/#f08a2a。

踩坑

  • 猫头按 RIG 原位置画会悬在趴低的身体上方（空一截），趴姿下头要下移 ~100px 压进身体。
  • 头发第一版只是一整片带轻微波浪的黄色，远看像披了块布；利希滕斯坦的金发辨识度来自「卷团 + 黑色 C 弧」。

仍可改进

  • 原片少女有泪珠和白领子（经典利希滕斯坦哭泣女孩），设定稿去掉了，我也没加；想更「漫画」可以加一个对白框。

21_kusama · 草间弥生无限波点

来源：迁移测试 A（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 scripts/engine/scenes/21_kusama.js。

实验时的文件名 scenes/05_kusama.js（124 行）。0.45↔0.9s 为 17.3%，相邻帧中位 2.98%，JS 侧 4–28ms。

蠕动的点 - 所有点的半径乘同一个「从猫出发的行波」：wave = 0.82 + 0.28·sin(dist·0.012 − 6t)。 - 整个房间的点从猫的位置一圈圈胀缩，像在呼吸。这一个函数就让全屏都活了。

点的布置 - 墙：大点（30px，间距 104）＋小点（10px，错位）两套六角网格，各带 ±25–50% 抖动。每个点是轻微椭圆加随机转角，像手画的。 - 地板：9 行，越近越大（6→28px）、越疏，压成 0.42 的椭圆做透视。 - 红裙白点 13px、间距 52，按 46px/s 顺着裙子往下爬（clip 到裙子剪影，y 偏移取模）。 - 猫：橘色区白点、白色区红点，各自往下爬。 - 脸颊上也画了一个红点（草间的身体彩绘），头上是红底白点蝴蝶结。

无限镜屋（窗） - 3D 格子灯：13×7×3，6 色。z 以 0.3/s 循环飞向镜头，透视投影 F150。 - 每颗灯是实心小核加 3.2 倍光晕，lighter 叠加。 - 坑：第一版灯随机散布、光晕很大，糊成了散景。规则格子＋小实心核才有镜面无限重复的感觉。

黄南瓜 - 5 瓣椭圆，绘制顺序是外 → 内。 - 每瓣按行排黑点：中列最大（9.5px），向两边、上下都缩小，点的大小也跟着行波变。 - 整体呼吸：缩放 1 ± 0.025·sin(5t)，以底部为轴。

结尾「自我消融」 - lt 1.0–1.26：红色覆盖层渐显，全屏 120px 六角点阵从猫的位置一圈圈胀到 0.47 倍间距。之后约 0.15s 只剩点阵在轻轻呼吸，给结尾一个落点（审片指出第一版没有停留帧）。 - 最后一帧停在红底白点的点阵上。 - 坑：第一版让点无限胀大，结果是白屏。半径必须封顶，最后停在点阵，不能停在纯色。 - 坑：裙子和墙都是红底白点，少女在画面里会溶解掉。终版把少女轮廓线加到 4.5px，猫白色区域的红点去掉，保住橘白分界。

27_kirby · 1966 漫威银河时代（Jack Kirby ＋ 四色胶印）

来源：迁移测试 C（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 scripts/engine/scenes/27_kirby.js。

实验时的文件名：scenes/k1_kirby.js（255 行）。每帧约 20ms，帧差 7.5%。

管线：同一份几何画两遍 1. 色版层：纸 #f4ecd6 ＋ 平涂 ＋ 本戴网点。墙浅蓝底上铺 C 网点（pitch 9、r 2.7、15°），地板深蓝底上铺紫网点（pitch 9、r 3.2、75°），皮肤是红点（pitch 7、r 1.5、75°）。整层 drawImage(color, 4, 3)＝套色不准。 2. 墨线层：白底，每个部件「白填 → 阴影 → 黑描边 6px」。合成时 multiply 叠在色版上，白色＝透明。逐部件填白会盖掉前面部件的线，所以只剩看得见的线，不需要 visibleLines。 3. Kirby 的黑块阴影＋羽化排线（spotted blacks＋feathering）：光从窗来（LIGHT=(-0.86,-0.5)）。 - 黑月牙：path ∩ ¬translate(path, LIGHT·d1)，d1=14。做法是先 clip(path)，再用「全屏矩形＋平移后的 path」做 clip(…,'evenodd')，最后 fillRect 黑。 - 羽化带：同样的取法，用 d2=30 得到一条带，带里画沿光方向的平行线（间距 9px、线宽 2.6）。 - 参数（d1/d2）：裙 16/34、躯干 14/30、袖 10/22、头发 12/26、猫身 16/34、桌面 10/18。 - 一个函数就能给任意 Path2D 打 Kirby 式阴影。

母题动画 - Kirby krackle：一簇 16–26 个黑圆。距离按 R·rnd^0.7 分布，越靠中心越大（R·(0.05+0.2·(1-d/R))），12fps 换种子，半径按 sin(18t+i) 脉动。6 簇沿窗外 S 形能量流移动（(k/6+0.42t)%1），能量流是橙边黄芯带＋锯齿墨边。热气也用 krackle（4 簇小的往上飘）。 - 速度线：端杯速度 |sin(min(1,lt/0.9)π)|，在杯底往下拖 9 根黑线，长 70–180·v，12fps 抖；肘后两道动作弧。 - 拟声大字 SLURRP!：lt 0.52 起 outBack 弹出，用 Bangers-400 132px（×0.82）；黑色挤出 7 层（每层偏移 (0.8d,d)）做出 Kirby 的立体积木字；红字上面 46px 带 clip 成黄（双色字）；底是 26 尖黄爆炸框；12fps ±3px 抖。 - 分格：主格 24..1534，右侧一格是猫脸特写，瞳孔随 cup 上移（lerp(14,-18,cup)）、往左看。背景是品红底＋黄网点＋44 根聚焦黑三角（12fps 换）＋头周围 6 簇 krackle。底部旁白框「BUT THE CAT IS WATCHING!」，左上旁白框「MEANWHILE, AT TEA TIME...」。计数器做成黄底黑框、带黑色错位投影的旁白框，放在右上格缝里。

角色：60 年代红色 A 字长裙、白色彼得潘领（两个椭圆）、前襟三颗黑纽扣、黑发箍（头部旋转坐标系里的椭圆弧，线宽 11）、外翻发尾（在 skirt 钩子里画，位于躯干后面）。椅子是 Saarinen 郁金香椅。

坑 - 拟声字一开始放在 (1000,300) 满尺寸，压住了窗和少女的脸。挪到 (990,318) 并缩到 0.82。 - 猫特写右侧的大黑椭圆让猫像玳瑁猫，改成贴边的窄月牙。 - 行星环要拆成后半弧（先画）和前半弧（后画），不然环会穿过星球。 - 仍可改进：画面偏「干净的波普漫画」，还缺 Kirby 那种方块化的手指、更夸张的透视和肌肉张力。

31_haring · 1982 凯斯·哈林

来源：迁移测试 C（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 scripts/engine/scenes/31_haring.js。

实验时的文件名：scenes/k5_haring.js（109 行）。每帧约 4ms，帧差 11.5%。

手法 - 纯色底：黄墙 #ffd51c、绿地 #16a54a、14px 黑地平线。 - 一切都是 13px 圆头黑线＋平涂，用 X.girl / X.cat 逐部件「填→描」。 - 跳舞小人：用修正版 X.limb 的胶囊做 7 段肢体＋圆头，先全部描 2×LW 黑，再统一填色，得到并集轮廓。4 个姿势（局部关键点，原点在脚底）8fps 硬切、不插值，这才是哈林的跳法；手旁加动作弧。 - 放射动作线：物体外围椭圆上的 n 根短直线（长 22–34、线宽 7–9），8fps 换角度。用在猫、少女头、杯、茶壶、红心、右侧小人上。 - 一切跟拍：bounce=|sin(t·128/60·π)|^0.6。少女 dy=−12·bb，猫错半拍。桌子以脚底为轴挤压拉伸（sy 1−0.07(1−bb)、sx 1+0.05(1−bb)），桌腿弯；茶壶跳 26px；窗框摇 ±0.025rad；地上的「跳起」横线长度随拍变。

母题动画： - 窗里的光芒宝宝：白色并集剪影，两帧交替爬；14 根光芒，长短 8fps 交替。 - 墙上 3 个跳舞小人（红/蓝/粉，相位不同，有一个镜像）。 - 桌上方的红心，跳动并带放射线。

角色：80 年代纽约少女。宽大红毛衣（下摆一道罗纹线）、牛仔蓝长裙、白高帮球鞋。脸上只留一个眼点和一道红唇（哈林的人物本来没有五官，留这一点是为了认人）。耳朵的粗黑圈看起来像随身听耳机，正好合年代。 坑：RIG.limb 的反向端帽在粗描边下会在关节处留洞（见②-1）。窗户横档要画在宝宝下面。RIG 的 hairLines 是细线，在哈林里违背「等粗线」，而且喝茶仰头时会穿过脸，所以去掉了。
