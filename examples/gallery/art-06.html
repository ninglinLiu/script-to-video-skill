16_2026 · 2026 扁平矢量插画 ＋ 全片笑点收尾

所有表演用全片帧号 F = t*60 写，关键数字逐条照抄 ../拆解/分镜表.md §4，方便和原片逐帧对表。 对照接触表（左原片｜右复刻）：../渲染/16_2026/cmp_E1…E4_*.jpg，片段 clip_2026.mp4（10.8–15.06s）。

画风（Dribbble 扁平＋颗粒）

  • 纯色块、无描边；体块只靠「同色系深一档的色块」分（毛衣亮面斜块 #f08b7d、猫大腿 #f3ad4c＋一道深色弧边）。
  • 颗粒点彩 stipple()：在形状里撒 2px 方点，密度是位置函数——粉圆 0.12 + 0.75·clamp((y-cy+120)/420)（越往下越密），淡紫块往右下密，太阳往右下密。静态部分全进缓存 fl_bg。
  • 角色层画完后用一张静态颗粒纹理 source-atop 叠上（5% 暗点 α70、3.5% 亮点 α90），颗粒只落在角色身上。
  • 光锥：26000 个点、宽度随 y 线性 56→150、透明度随 y 衰减、靠中心更密，缓存成 340×420 贴图，跟吊灯一起绕 (1010,0) 摆。

少女（RIG 基础上自写姿势）

  • 躯干/颈锚点：RIG.girl({s:1.12})；头部再调一次 RIG.girl({s:1.344, dy:43.7})——相当于头部围绕颈点放大 1.2 倍，扁平插画的大头比例。脸、刘海、后发、丸子、眼/唇/耳锚点都取自它。
  • 手臂：RIG.ik2(肩, 目标, 150, 140, -1)，三套目标点按进度混合：打字（两手在键盘上以 22 rad/s 交替起落 7px）→ 摸猫（688–704，近手在猫背上画小圆）→ 惊呼（791–798，ease.outBack 举到下巴前，手指张开）。
  • 表情：闭眼弧＋上扬嘴（<686）→ 圆点眼＋高光、小 o 嘴（686 起，o 用 outBack 弹出）→ 大眼＋大张嘴＋舌头（791 起）→ 838 帧后改成挤眼「<」（原片终帧也是闭眼）。
  • 紧张线：3 道，从头顶前上方放射，长度 outBack 弹出；颜色 793 淡粉 → 796 全红（RGB 插值）；830–888 每 2 帧随机抖 ±2.5px，头部同步抖 ±2px。
  • 裤腿/袜/鞋自画（RIG 是长裙）。

猫（姿势库 + 插值）

每个姿势是一组局部关键点（朝右、原点＝质心）：身体 10 点、白胸 6 点、大腿椭圆、背纹 3 段、头、两前腿、后腿、尾巴 4 个贝塞尔点、gy（脚底到质心）。 姿势：SIT_F（地上坐，从原片 10.95s 量）、SIT_T（桌上坐，原片朝左实测后镜像成朝右存）、LEAP（水平拉长）、LAND（前爪向下）。mixPose 逐数值 lerp。 变换：translate(质心) → [绕脚底 或 绕质心] rotate → scale(dir·sx, sy)，挤压拉伸都绕脚底，所以蹲下时脚不离地。

杯子与碎裂

  • 杯子 x：分镜表 16 个实测点线性插值（744:981 … 796:801）；790–796 开始外倾 -0.12。
  • 坠落 796–815：9 个实测中心点 Catmull-Rom（实测重力≈1.75px/帧²），旋转 -0.12 - 2.3·q^1.3；身后 6 颗咖啡滴取杯子过去 1.3 帧间隔的位置、越早越小。
  • 815 落地：7 道冲击放射线 8 帧淡出；两块大碎片用分镜表三点（818/824/834）拉格朗日抛物线，834 落地后停住；9 颗小碎屑抛物线、各自落地高度 893–911 停住；咖啡渍宽 818:140 → 822:220 → 826:235（ease.out）；两圈灰涟漪扩到 560/460 宽、838 前淡出；把手半圆＋茶包标签留在地上。
  • 拍杯动线：杯子右侧 3 道短线，击中后 12 帧外扩淡出。

  • 吊灯：damped(F, 686, 0.055rad, 周期26帧, 衰减22帧) + damped(F, 830, 0.045, 22, 20)，光锥一起摆。
  • 植物：damped(F, 697, 0.035, 22, 18)（晃）+ damped(F, 821, 0.05, 9, 26)（抖，周期短）；龟背竹每片叶再加一点相位不同的自摆。
  • 云 15px/s 左移（0.25px/帧）；小飞机 177px/s 拖虚线尾迹（12.0s 在 x≈440、13.75s 在 x≈750，对上原片）；太阳光芒 0.35 rad/s 转；17 个装饰符号 4fps 沸腾（±1.5px、±0.09rad）。

25_ghibli · 1988 吉卜力式手绘水彩背景美术

来源：迁移测试 B（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 scripts/engine/scenes/25_ghibli.js。

实验时的文件名：scenes/c4_ghibli.js（约 270 行）。每帧中位 17ms，首帧 619ms（水彩底版缓存）；帧差 5.1%。

水彩渲染器 - deform(pts, depth, amp, r)：中点位移。每轮在每条边中点沿法向推一个近似高斯量（3 个均匀数相加），幅度和边长成比例（min(1, len/80)），每轮 amp×0.6。 - wash(g, pts, color, {layers, alpha, amp, seed, edge, blend, fill})：先 deform 3 轮得到基形；每层再 deform 2 轮，用 multiply 低 α 填充（透明颜料叠色），并以 α=edge 描一圈 1.6px 同色边。描边逐层叠加，就是颜料在边缘沉积的水痕边。fill 可以传渐变（天空、墙）。 - 常用参数：大面积墙 layers 5、α 0.4、amp 12；色晕 layers 3、α 0.045、amp 40（大幅变形）；木板 layers 3、α 0.5、amp 3、edge 0.14；不透明的白（窗框、桌布、云）用 blend:'source-over'、α 0.9–0.95。 - 墙 = 径向渐变洗染（窗边亮 #fbf3e0 → 角落 #dcc49a）＋ 28 块大幅变形的透明色晕（暖黄、粉、蓝灰、浅绿交替）＋ 两角暗晕。护墙板和地板逐块换色调洗染。最后 multiply α 0.3 叠一层高频纸纹颗粒。 - 云：白色不透明圆团（16 个 puff，用 wash 画边）＋ source-atop 叠底部蓝灰渐变，缓存成精灵。大樟树也是精灵，绕树根转 ±0.025rad。

赛璐璐角色 cel(c, p, base, shade, dx, dy)：先整块填阴影色，再在 clip(p) 里把自身朝光平移 (−dx, −dy) 后填基色，只剩背光侧一道月牙阴影。最后描 2.4px 暖褐线 #4a3428。一个函数就是吉卜力式的两色赛璐璐。

母题动画 - 白纱窗帘：两幅，下摆鼓起 q²·(90 + 70·gust)，gust = 0.55 + 0.45·sin(3.2lt + 相位)，再叠 sin(7lt + 6q) 小波纹；3 层半透明 wash，固定种子，所以边缘不沸腾。 - 窗外 360 根草叶：风是一阵一阵的，wind = 0.5 + 0.5·sin(3.1t − 0.018x)，相位沿 x 推进，看得出一道风浪扫过草坡。 - 云飘 22–30px/s；树冠轻摇；墙上 34 个 komorebi 光斑（screen 暖黄径向渐变，位置用 noise 漂，亮度 sin(5t + 1.7i) 闪）；桌上雏菊点头；少女长发被风吹向右后（7 点 smooth，wind 推动）；红蝴蝶结飘带抖动；桌布垂边摆动。

角色：长金发＋大红蝴蝶结（致敬魔女宅急便，不复制角色）、青色长裙＋白围裙＋白袖口；猫是暖橙＋米白赛璐璐。背景里靠墙的扫帚是彩蛋。 角色的水彩填色：审片说「背景像，人物不像（扁平矢量）」。把角色先画进离屏 L，另起纹理层 M（纸纹颗粒 α 0.8 ＋ 40 块透明色晕 charBloom，α 0.1、amp 16），M 用 destination-in 按 L 的剪影裁掉，再以 multiply 叠回画面。线色从 #4a3428 调软到 #6a4a38。 窗帘：审片说不飘。gust 频率 3.2 → 5.4，鼓起 q²·(60 + 150·gust)。

坑 - 色晕 α 0.07×4 层、颗粒 multiply 0.5 时，墙面像发霉的旧羊皮纸。吉卜力的房间是亮的：色晕 α 降到 0.045×3 层，渐变整体提亮一档。 - 第一版用两个矩形 wash 拼墙（右侧更暗），x≈1100 出现硬接缝。暗部要用大幅变形的多边形（amp 60），不能用矩形。

仍可改进：人物还是平面，可以加吉卜力式的发丝高光块；地上的光斑里可以加窗帘影子的流动。

33_rubberhose · 1930 橡皮管卡通

来源：迁移测试 D（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 scripts/engine/scenes/33_rubberhose.js。

实验时的文件名：scenes/r2_rubberhose.js，每帧约 20ms。

管线：纸色单色底（墙纸竖条＋菱点、地板砖缝、角落水彩压暗，缓存）→ 窗外天空（太阳脸、云、树）→ 窗框和圆点窗帘 → 椅 → 桌（弯腿＋跳舞花）→ 少女 → 猫 → saturation 灰去色＋multiply #f2e8d2 做褪色 → 胶片层。

关键参数 - 节拍弹跳：bnc(tq, ph) = |sin(π(tq/BEAT + ph))|，BEAT = 60/128。每个物体绕自己的着地点上弹 amp 像素：落地时压扁 sx=1+0.09k、sy=1−0.09k，腾空时拉长约 5%。各物体相位错开 0.25 拍：桌 0.5、少女 0.25、猫 0.75、太阳 0；蝴蝶结 0.05，比身体晚一点，算作跟随。 - 步进：所有角色和母题用 tq = floor(t·12)/12（一拍二）；端杯也按 12fps 步进；胶片层用 floor(t·24)。 - 角色画法：骨架只取锚点。 - 头：围绕 headC 画半径 82 的大圆脸。 - 派切眼：白眼眶＋黑瞳，黑瞳上用 arc(−1.45..−0.85) 切掉一块楔形；上方 3 根睫毛。 - 手臂：橡皮管 = 肩到手的一根二次贝塞尔，粗细恒定，黑边 +10px。 - 白手套：4 指、外翻袖口、手背 3 道线。 - 波点裙长到脚踝（端庄款）。 - 猫：身体用 RIG.smooth(K.bodyPts)，中灰 #a39a84（=橘），虎斑 #5e574b，白胸白爪 #fbf7ec；尾巴是波浪橡皮管 sin(7q − 9tq)·26q。 - 胶片层： - 抖片 ±1.5/±2px。 - 闪烁：每格叠 α0.02–0.09 白，再叠 0–0.06 黑。 - 划痕：3 条竖线，按 floor(t·6) 换位置，所以一条划痕能活好几格。 - 每格 14 个灰尘点＋偶尔一根毛发。 - 颗粒层每格随机平移 ±20px。 - 圆角片门：roundRect r60，加暗角。

母题动画：所有物体随拍弹、太阳脸光芒旋转 1.6rad/s 且脸随拍点头、跳舞的花（茎左右 ±0.35rad，叶子当手挥，花瓣转）、烟圈一拍冒一个、窗帘下摆随拍甩、胶片闪烁和划痕。运动面积 40%，但大部分是胶片噪声（见 ② 第 5 条）。

坑 - 骨架的猫身体是折线，卡通里一眼看出直边，必须 smooth。 - 整片要压成单色，必须在角色画完之后统一做一次 saturation 去色，不然手套、杯子会残留暖色。

35_shinkai · 2016 新海诚光影

来源：迁移测试 D（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 scripts/engine/scenes/35_shinkai.js。

实验时的文件名：scenes/r4_shinkai.js，每帧约 71ms。

管线：写实室内（墙面冷暖渐变、木地板透视缝、铝框窗、挂历、书桌，缓存）→ 天空＋积雨云＋电线杆电线＋远处屋顶＋飞机拉线＋鸟 → 玻璃水珠 → 白纱窗帘 → 地板和墙面的窗形光斑（墙面光斑里有窗帘的影子在摆）→ 盆栽 → 猫、少女（赛璐珞）→ 热气 → 丁达尔光柱＋光尘 → 镜头光晕 → 泛光 → soft-light 冷暖分离。

关键参数 - 赛璐珞函数 cel(c, p, base, shade, rim, {sd, rw, lx, ly})： - 阴影 = clip(p) ∩ ¬(p 平移 (lx·sd, ly·sd))。用 evenodd 实现：一个大矩形 + 平移后的 p，作为 clip。 - 亮边 = clip(p) ∩ ¬(p 反向平移 rw)。 - 光从窗来，lx=−1、ly=−0.55，所以阴影落在右下侧。sd：大部件 22–30，脸 10，小件 8；rw 3–9。 - 线色 #6a4632，线宽 2.2。按部件顺序"填 → 影 → 亮边 → 描线"，遮挡自然正确，不需要 visibleLines。 - 猫在窗下是逆光：lx=0.5、ly=1，暗部在下侧，头顶和背上再加一圈 lighter 的暖色亮边 rgba(255,220,160,.55)。 - 颜色：肤 #ffe8dc/#f2b6a8；金发 #f8d681/#d8a050；白校服 #fbfbfe/#b9c3dc；藏青 #2c3a66/#1b2446。天使环：后脑一道 9px 亮弧 rgba(255,250,226,.85)。 - 动画眼：白 8×12、虹膜纵向渐变 #1f3f7a → #3f7fd0 → #9fd4ff、两颗高光、上眼睑 3.4px 加一根眼角睫毛。 - 积雨云：70+12 团。①所有团块画蓝灰剪影（线性渐变 #b7c6e6 → #8297c6）②每团在偏向太阳 (+0.22r, −0.3r) 处画一个 0.82r 的白色径向亮球 ③整层 blur 3px，再叠 55% 清晰层。每团半径以 0.05·sin(1.3t) 呼吸，整体以 10px/s 漂移。 - 光晕： - 太阳核：r130。 - 10 根星芒：长 90/170，以 0.25rad/s 旋转。 - 横丝：840×4。 - 5 个六边形光斑：落在太阳 → 画心连线上 0.45/0.75/1.25/1.6/2.0 倍处，α 0.04–0.12。 - 丁达尔：3 个楔形，模糊 18px 后缓存，screen，α 0.75 + 0.25·sin(3.4t)。光尘 60 颗，径向渐变，闪烁。 - 泛光：整帧画进 480×270 的小画布 → blur 6px、brightness 1.1 → screen α0.28 放大回叠。

母题动画：云团翻涌和漂移、飞机拉线、鸟群扇翅、一颗水珠沿玻璃滑下（带水痕）、白纱窗帘和它投在墙上的影子在摆、盆栽叶子摆、发丝被风吹、星芒旋转、光柱明灭、光尘。运动面积 3.0%。
