10_nouveau · 1896 新艺术运动（慕夏海报）

文件：scenes/10_nouveau.js（约 300 行）。性能：warm 平均 29ms、最大 37ms，首帧（建缓存）≈80ms；确定性通过（同一 lt 两次逐像素相同）；lt 0.35→0.65 运动差分 13.1% 像素。片中停留 0.70s（T09 有机波浪转场 0.24s，从 (1330,320) = 少女光环长出来）。

管线

  1. 底版全缓存 nv_bg：灰绿→米绿→桃色三段竖渐变（#b9cba0→#cfd3a6→#ecc9a2，只铺内框 34..1886×32..907）；圆点花纹 = 环 r10 + 心点 r2.6，行距 54、列距 62，奇数行错 31（菱形交错），色 rgba(120,140,100,.38)；240×135 的 fbm 小图放大 α0.5 叠石版斑驳（比全屏算噪声快几百倍）；马赛克地砖带 20×24 一格、9 色循环 (k*7+(k>>2))%9 打散；绿横幅 #8fac80；标题 Marcellus-400 76px、letterSpacing 12、先 7px 深棕描边再填奶白；金框 = 外 6px 金 #c9a24a + 内外两条 2px 深棕。
  2. 可变线宽路径 ribbon(pts, w(q))：点列先 Catmull-Rom 加密（每段 4–10 点），每点沿法线两侧各偏 w/2，拼成闭合多边形 fill。所有「鞭线」都是它：茎、叶、铁艺桌腿、横幅卷草、头发、热气。swellW(wmax) = 两头尖中间粗（sin 包络），这就是慕夏线条的粗细呼吸。螺旋收尾 spiral(cx,cy,r0,a0,turns,dir)：半径线性收到 15%。
  3. 慕夏式「外轮廓粗、内线细」——整体剪影错位法：角色（猫＋少女＋头发＋披帛）全部画进离屏层 L（RIG 的 both 模式，lw 2 → 内线按部件顺序遮挡正确）；再复制 L 用 source-in 染成深棕 #4e3320，在主画布按 (-1.5,-1.5)、(3.5,4.5)、(2,2.5) 三个偏移垫在 L 下面。结果：剪影外缘一圈 1.5px，右下侧 4–5px 厚边；内部线保持 2px。只多 3 次全屏 drawImage。
  4. 颗粒 P.grain('nv', .05, 暖棕, .14) 盖最上层，像石版印刷。

母题动画（0.7s 内都要看得见）

  • 太阳升起：按原片测量（509 帧 (583,400) → 530 帧 (576,299)，≈-5px/帧）写成 sy = 400 - (lt-0.267)·288、sx = 583 - (lt-0.267)·20，lt=0 时在 477（藏在山后），lt=0.7 到 275。山丘色带画在太阳之后 = 天然遮挡「从山后升起」。
  • 铅条光芒转动：14 根放射铅条从日心 r92→r420，角度 +lt·0.9·0.25 慢转并带 ±0.04 摆动；铅条随太阳移动，所以整窗玻璃分割都在变——这是窗里最显眼的动。
  • 彩色玻璃边带：沿拱形内缘（直边+椭圆弧 rx219 ry130）每 17px 放一块 14×14 色片，按切线旋转，6 色循环。
  • 罂粟/百合摇摆：花头水平位移 sin(7.5t+φ)·13 + sin(3.1t+2φ)·5，茎是 ribbon 的三控制点曲线只推上段；左右两丛相位相反；叶片 0.3 倍幅度。
  • 光环转动：少女光环 R172，18 颗圆钉 +0.9t 转，内圈 32 片玫瑰窗花瓣 -0.63t 反转；猫光环 R106 八瓣橙花 -1.1t + 金色虚线环 lineDashOffset 走。
  • 头发：先一大块发团（16 点 smooth，外缘按 sin(6t+y·0.035)·9 波动），再 7 绺背后卷发 + 2 绺肩前卷发：每绺 12 点 S 曲线 sin(7.4q+φ-7t)·(6+20q)（行波往下传）、末端接 1.2 圈螺旋、宽 14–18 → 2.5 递减，奶黄高光芯 + 深金细线。头顶外缘 6 个小卷做体积。所有点跟随 G.A.headC 的偏移（喝水仰头时一起动，越往下跟得越少）。
  • S 形装饰热气：3 条奶白 ribbon（宽 26/20/14）+ 1.8px 棕描边 + 中线，sin(4q+φ-6t)·(18+70q) 行波，横向间距随高度 ×(1+2.6q) 散开，末端 34px 螺旋；整体 lean = -90 - 160·cup 往左倒——踩坑：choreo 把杯子举到嘴边，热气如果竖直升会横穿少女的脸，必须随 cup 往窗那边倒。
  • choreo：端杯、仰头、眨眼、甩尾、呼吸全用 RIG；碟子留在桌上（杯子被端走后桌面不空）。

踩坑

  • drawGirl(mode:'line') 叠在最上层会把被遮住的部件轮廓（远侧袖子）画穿躯干（09 标杆也有）。改成在离屏层里用 both 模式按部件顺序画线，再整体做粗外轮廓。
  • 头发最初是 7 条 34px 宽的长带，像香肠/面条；慕夏头发 = 一块发团打底 + 细绺 S 卷 + 螺旋收尾，宽度 ≤18。
  • 自检差分别拿 lt<0.33 的帧：引擎在转场开始后 20 帧内有 1.03 倍「拍点冲击」缩放，差分会全屏发红。

仍可改进

  • 猫仍是 RIG 的坐姿（白色直腿），设定稿是趴卧的毛茸茸橘猫；慕夏味主要靠光环和粗细线撑。
  • 标题用 Marcellus，设定稿是更圆的手绘新艺术字形；可以手写一套字母路径。

11_cubism · 1912 分析立体主义（毕加索／布拉克）

文件：scenes/11_cubism.js（约 280 行）。性能：warm 平均 13ms、最大 19ms，首帧（建缓存）≈100ms；确定性通过；lt 0.34→0.46 运动差分 6.9% 像素。片中停留 0.47s（T10 碎片转场 0.24s）。

管线

  1. 底版全缓存 cb_bg——「透明叠面」：核心函数 plane(g, pts, col, alpha, r)：每块面一条线性渐变，起点取第 0 顶点、终点随机取另一顶点，三个色标 = 混 25% 米白 → 原色 → 混 40% 深棕，alpha 0.18–0.7。叠法：18 块手排大面（照原片构图位置）+ 桌下 9 片放射扇面（自 (1000,1090) 发出，亮暗交替 α0.3）+ 70 片随机 3/4 边形（避开右上年份区）。多层半透明渐变叠起来就出现分析立体主义那种「透明、互相穿插、每面一亮一暗」的空间。
  2. 肌理面：4 块点画（9px 菱形格 r1.6）、4 块排线（7px 间距斜线）、左缘一页横线纸。
  3. 布拉克短划砂纹：9000 个 3–8×1.5px 小划，55% 米白 α0.28 / 45% 深棕 α0.16——原片那种「砖纹」质感就靠它。
  4. 46 条贯穿细直线（1.3px α0.55）= passage。
  5. 仿木纹 wood()：沿长边画 S/6 条波浪线，过节疤位置加高斯鼓包 14·exp(-(u-k)²/0.01)，节疤 4 圈椭圆。用于桌面和右侧木板（布拉克的梳纹假木）。藤编椅背 = 10px 菱形孔点 + 双向斜线。
  6. 窗格碎面滑动：窗景单独缓存成 560×540 大图（55 片蓝灰切面 + 3 条斜光束 + 埃菲尔铁塔 + 海鸥弧），四格各自 clip 后以不同偏移取景 dx = sin(9lt+1.7i)·18 + 10fps 抖动 ±3、dy = cos(7lt+i)·8——同一窗景在四格里错位 = 多视角拼合；每格另有一片半透明三角以 260px/s 横向滑过。
  7. CAFÉ 模版字跳动换位：AlfaSlabOne-400 104px 画进离屏小层，12fps 卡点（st=floor(lt·12)），顺序表 CAFÉ/ACFÉ/CAÉF/CFAÉ 轮换，每步每字 y ±13、旋转 ±0.11rad（hash 取）；然后 destination-out 切出横竖断口 = 模版字（断口透出底下的叠面，比画纸色条真实）。
  8. 报纸 JOU：缓存 300×190 小图（LibreBaskerville-700 84px「JOU」+ 12px 标题「LA BATAILLE / S'EST ENGAGÉ UN CHAT」+ 三栏灰色假字），每帧以 8fps 微颤（旋转 ±0.0125rad、x ±1.5px），右上折角按 sin(20lt) 翻。
  9. 角色 = 自写切面器 facetize：RIG 平涂（fill 模式，无线）进离屏层 → 读回该包围盒像素 → 抖动三角网（每格随机选对角线）→ 每个三角在质心取色，×(0.8+0.38·rand) 明暗、再做一条从顶点 0 到顶点 2 的亮→暗渐变 → 三角不裁剪直接画回去（质心 alpha<120 的跳过）。不裁剪是关键：剪影边缘被切成锯齿直边，有的三角还伸出轮廓外——就是立体派「平面溢出轮廓」的感觉。
  10. 少女 cell 58（大面），发区再用 cell 26 细切一遍、只切「像金发的颜色」（only: R>150 && B<130 && R-B>60），猫 cell 26。
  11. 顶点每 8fps 抖 ±8% cell、16–35% 的三角明暗跳 ±12%（boil）→ 角色在「微动」，原片 548–562 帧猫区域就是这样。
  12. 切完再补毕加索式的结构：脸重铺两块肤色明暗面（切面会把金发色带进脸）+ 前半张脸蓝灰面 α0.82 + 正面杏眼（侧脸上画正面眼）+ 螺旋耳 + 红唇；白领两块明暗三角 + 三颗扣；裙摆从腰部 8 条放射切线 + 亮暗交替楔面；外轮廓用直线段 segs()，每段两端各外伸 10–16px（线画出界）。猫：六边形直线头轮廓、bodyPts 直线身轮廓、黄色菱形眼 + 竖瞳、侧面三角鼻。
  13. 最上层 5 片 α0.2 的叠面压在人和猫身上并以 sin(6lt)·8 错动——把角色「嵌」进空间，不像贴在背景上。

色板

纸 #d6c8ac、米白 #ece3cf、赭 #b8975f、棕 #6e5538、深棕 #3a2c1e、灰 #a8a395、蓝灰 #8e9eab、暗灰 #5a5852；窗景 #c9d3da/#8fa3b3/#e4e6e2/#6f8597/#b4c1cb/#5f7385；裙 #6a7a8b、袖 #3c4857（必须比裙深，否则端杯的手臂整个融进裙子切面里）、皮肤 #e2cfae、金发 #c9a256；猫 #c8773a/#e8dfc9。

踩坑（重要）

  • 不确定性：第一帧和之后不一样。 两个原因叠加，都只在第一帧出现：① 要 getImageData 的离屏层第一次画时走 GPU，读回后 Chrome 把它转成 CPU 光栅，抗锯齿不同 → 质心取色不同 → 三角颜色不同；② 更主要的：离屏层的 context 状态（facetize 里设的 lineJoin='round'、segs 的 lineCap='round'）会残留到下一帧，第一帧用的是默认 miter/butt。修法：自建层 getContext('2d',{willReadFrequently:true})，每帧开头用 g.reset()（清像素 + 清状态）而不是 clearRect。用 hash 对比「同一 lt 连渲三次」才查出来。
  • 切面 cell 34 时满身小三角，像 low-poly 3D 模型而不是立体派；58 才有「大块明暗面」。
  • 第二遍发区细切一开始用圆形 clip，把半张脸也切成了金色——加了按颜色过滤的 only。

仍可改进

  • 少女整体轮廓仍是 RIG 的写实曲线，切面只改了边缘；更彻底的做法是把肩、肘、膝都换成折线骨架再切。
  • 原片色调更暗、明暗对比更强（大块深褐面更多），我这版偏亮。

12_bauhaus · 1923 包豪斯海报

文件：scenes/12_bauhaus.js（约 210 行）。性能：warm 平均 5ms、最大 9.5ms，首帧≈85ms；确定性通过；lt 0.34→0.46 运动差分 4.9% 像素（黑杆、格窗、同心弧、猫、球、人偶都在动）。片中停留 0.47s（T11 蓝方块/红圆/黄三角/圆孔转场 0.20s，原点 (1330,590) ≈ 红圆圆心）。

管线

  1. 底版全缓存 bh_bg：米白旧纸 #ebe3cf + 320×180 fbm 小图放大 α0.5（做旧斑驳）+ 贯穿细斜线 (40,170)→(1900,840)（压在窗后）+ 左上黑横条 (60,61,256,13)、红竖条 (292,105,24,468) + 竖排 bauhaus（Poppins-800 210px，rotate(-π/2) 后水平缩放到正好 820px 长，原点 (262,1000) 自下而上读）+ 灰小方块 + 地线 (345,898)-(1860,915) + 黄直角三角 + katze（Poppins-800 150px，红 #d3262b）+ 右下两行 Poppins-600 31px + 黑面桌/镀铬管腿（三色线性渐变）+ 布劳耶悬臂椅（同一路径描 15px 深灰 / 10px 镀铬 / 3px 高光偏移 2px）+ 两层颗粒（暗点 0.02 密度 α0.35，旧印刷黑斑）。
  2. 红圆单独缓存 520²：底色 + source-atop 叠 fbm 浅色斑 α0.55，模仿丝网/石版的不匀墨。
  3. 角色、构成全是几何体：没有任何曲线描边，只有圆、方、三角、粗杆。

母题动画

  • 斜长黑杆像指针转：按原片逐帧量的角度（575–579 帧 28°，581 帧 33°，583 帧 37°，585 帧 42°，587 帧 46°，591 帧 49.5°）写成 deg = 28 + 21.5·easeOut(clamp((lt-0.26)/0.22))。转轴 = 毂心 (1125,195)（原片对比 576/590 帧确认：毂不动、下端扫下来），杆 27px 从 -432 到 +150，细平行线偏 30px，红短杆偏 -30px，毂内弧跟着转。
  • 蒙德里安格窗轮换：4×4 格（内框 366..794 × 126..561，格 100×101、缝 9.5），6 个格子参与轮换，13fps 卡点 step=floor(lt·13)，每格相位不同、(step+2·sw)%9 < 6 才换（不是每拍都换，节奏不机械）；轮换色只用红黄蓝米浅蓝灰。图样格（9px 方格纸）、四分之一圆格保留。
  • 同心弧：红圆右侧 6 条弧，起点相位 sin(9lt-0.7i)·0.05 波动、半径 ±3 呼吸、弧长在 0.4s 内从 55% 扫到 100%——像声波往外推。
  • 杯上热气：一根 2.2px 正弦细线（26 个周期/170px、-18t 行波），线性渐变淡出。
  • 猫拨球滚一下：右前爪 tap = sin(clamp((lt-0.05)/0.16)·π) 往前伸 36px 再收；蓝球 r31 在 lt 0.13→0.47 以 easeOut 从 x712 滚到 816，转角 = 位移/半径（白直径线＋白点看得出在滚），滚动中身后两条速度线。尾巴 = 26px 粗橙弧 + 同宽虚线深橙条纹，角度跟 choreo.tail·0.5。

角色的几何化（锚点全来自 RIG）

  • 施莱默人偶：头 = 圆 r70（G.A.headC + (14,-18)），金色几何发片 = 后半个头的扇形（-1.95→1.15rad）+ 额前三角 + 发髻圆 r34 + 背后半圆发片（G.A.back）；脸 = 黑竖条眼（眨眼变横条）、红方腮、短黑口。头部整组绕 G.A.neck 按 G.tilt 转（喝时仰头）。躯干 = 蓝梯形 + 后半黑梯形（随 breathe 起伏）；裙 = 黑扇面 r178 + 蓝梯形；四肢 = 粗黑圆头杆，关节 = 米白圆盘 + 5px 黑圈 + 黑心点。近侧手臂直接用 G.A.shoulder/elbow/hand（RIG 的 IK 端杯），远侧手臂平放桌上（复现原片那只伸向桌面的手）。
  • 猫：身体圆 r100（K.box 推算的 (536,805)，随 breathe 缩放）+ 左侧 4 条深橙横条（clip 在圆里）+ 右下米白扇面（橙白块面）；头 = 104 方块（K.headC + (14,48)，随尾巴相位微转 ±0.08rad）+ 黄三角耳 + 米白下半脸 + 深橙额带；眼 = 白圆 + 黑竖条瞳。

30_matisse · 1947 马蒂斯《爵士》剪纸

来源：迁移测试 C（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 scripts/engine/scenes/30_matisse.js。

实验时的文件名：scenes/k4_matisse.js（167 行）。每帧约 25ms，帧差 9.3%。

构图：墙＝《波利尼西亚》双蓝棋盘（#1d4fb8 / #4f95dc，每格 240×236 剪纸块），窗＝《伊卡洛斯》（钴蓝底、黑人形、红心、黄星），地＝翠绿 #1f9a5a 加黑踢脚条，桌面是黑剪纸，椅子是黄剪纸。

手法 1. 剪刀折线 cut(pts)：沿轮廓每 14–24px 取一个点，加 ±2–2.5px 种子抖动，点与点直线相连。自己生成的形状一律这样处理。 2. 海藻（关键）：一根锥形茎，加 2×lobes 根左右交替的圆头胶囊手指。手指角度 ±(1.05−0.55u)，长 width·(1−0.45u)，宽 width·(0.34−0.12u)。所有子路径 addPath 进同一个 Path2D，用 nonzero 一次填充，得到并集，投影也只算一次。不要用「沿脊线调制宽度」：第一版这样做，出来的是毛毛虫和 Z 字闪电。 3. RIG 角色手剪边：RIG 不给点列，所以角色层整层做像素位移。静态位移场是 fbm(0.028x, 0.028y, 2)·9，dx、dy 各一套，只处理 bbox (330,470)-(1600,980)，约 15ms。 4. 纸的投影：shadow 偏移 (5,6)、blur 4、rgba(10,20,40,.3)，表现钉在墙上的纸。 5. 水粉刷痕：缓存 2600 道长条笔痕（60–300px、宽 6–22、黑白各半、α .04–.13、倾斜 −0.25rad），整幅 overlay。

母题动画： - 海藻像纸片一样绕根部摆 sin(2.8t+φ)·0.13，卷边用 scaleX 0.93–1.0 呼吸。 - 伊卡洛斯：7 颗不规则黄星，转着闪（scale .82+.22sin(7t+1.9k)）；黑人形上下漂；红心跳（1+.18·max(0,sin 9t)）。 - 两只白鸟扑翅（scaleY .55+.45cos 13t）。 - 一片粉纸翻飞落下（scaleX=cos 6t）。 - 热气是两根白色小剪纸。

角色：马蒂斯《罗马尼亚衬衫》。白宽袖衫，前襟一条钴蓝刺绣带（红黄交错的小三角），袖上随手臂旋转的红/蓝刺绣横带（clip 在 upperArm 里），红长裙＋黑腰带，金发是 5 个剪纸卷团。五官只用剪纸碎片：黑杏仁眼、红唇三角、粉腮圆片。 坑：飘落的纸片第一版轨迹划过少女的脸，改到左墙。计数器底下垫一张白剪纸片，否则黑字压在钴蓝上看不清。

36_picasso_blue · 1903 毕加索蓝色时期

来源：迁移测试 D（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 scripts/engine/scenes/36_picasso_blue.js。

实验时的文件名：scenes/r5_bluepicasso.js，每帧约 24ms。

管线：蓝单色平涂底稿（墙、地、窗外夜海和月亮）→ 宽而干的笔触重画，再糊 7px 叠 80% → 极淡的干刷细丝 → 窗框原样拷回，加小笔触 → 桌单独一层 → 环境粗轮廓（不抖）→ 海浪、月光碎影、云 → 角色（整体拉长）→ 角色小笔触＋冷光渐变 → visibleLines 粗轮廓 → 披肩褶线 → 慢热气 → 画布纹＋冷暗角。

关键参数 - 色板：#132240 / #1d3866 / #2d5a94 / #6b8fb6 / #b6c8d8 / 青灰 #3b6878，严格单色。 - 橘白猫用明度区分：橘 = 中蓝 #4f719a，虎斑 #273f66，白 = 浅蓝 #b6c8d8。金发 = 最亮的蓝灰 #cbd8e0，肤色 #90a9be，发色要比肤色亮一档才读得出"金"。 - 墙笔触：cell34、len110、w34，jitter 4，竖向 ±0.5·noise(0.003)；色板 mixBase 0.8；之后 blur 7px 叠 α0.8。地面笔触同参，横向。 - 干刷细丝：900 条，α0.07，长 30–90。 - 拉长：少女 DOMMatrix().translate(1240,932).scale(0.84,1.12)，以脚底为轴；猫 scale(0.82,1.14)，以 (540,905) 为轴。同一个矩阵用在三处：Path2D.addPath、离屏 setTransform、visibleLines 回调里的 setTransform。 - 披肩：从 forehead/headTop 罩下，经 nape、back，落到 waist+70，色 #6b8fb6，褶线 rgba(20,40,80,.6) 4px。长指：3 个细长椭圆 22×4.5 绕杯。 - 轮廓：普鲁士蓝 #0c1830，5px，不沸腾。蓝色时期的轮廓线是笃定的，不该抖。 - 慢：呼吸 sin(1.8t)·0.026（幅度约为共享编舞的 2 倍、频率约 0.45 倍）；端杯用 1.25s 举起（共享编舞是 0.9s）；热气按 0.5 倍时间升。

母题动画：窗外海浪横移（越近越快，速度 20 + 0.25·(y − 400)）、月光碎影 14 条闪烁、一条苍白长云横过月亮、缓慢呼吸（人和猫）、端杯、热气。运动面积 3.2%。

坑 - 第一版给猫和头发留了一点赭色（想参考《老吉他手》），独立审片判定破坏单色。蓝色时期就该全蓝，用明度区分。 - cell16、len40、w14 满墙竖刷读成"下雨/毛毯"，是印象派，不是蓝色时期。要宽、长、低对比，再糊一层。 - 宽笔的圆头密排成"人头阵"（见 ② 第 11 条）。用糊 7px 压住了，根治要给 strokes 加 cap 参数。 - 桌子区域如果用矩形 mask 排除在大笔触之外，地面上会留下一块平涂矩形补丁。桌子要单独成层画在笔触之后，不要在笔触里挖洞。
