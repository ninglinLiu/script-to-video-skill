怎样从参考变成可用组件

这次不是把图片当成模板，也没有把所有风格同时塞进一条片。素材包按三个层次组织，每层都有明确用途。

1 / 原样保存可复用资产

weilanx 的已跟踪文件由固定 Git 提交导出，保留代码、预览、配方、8个工作流、示例工程、测试与许可。没有把本地改动或未跟踪文件混进上游包。原图在 Skill 内可以离线查看。

2 / 蒸馏为选择与接力规则

先确定解释动作：比较、分支、传播、累计、证据更新、流程协作。再选最能表达这个动作的组件。每条记录连到预览、配方与代码；一个项目锁定主风格，跨章节沿用字体、配色和对象身份。

3 / 用真实渲染检验

第一批六条小样测试双内容替换；完整章节测试账单、现价、路径、证据之间的继承。历史片单保留用户否决的版本。源码能运行、画面能变，不等于内容好看或长片已验证。
