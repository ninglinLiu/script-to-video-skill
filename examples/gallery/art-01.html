01_cave · 40,000 BC 洞穴岩画（纯代码）

文件：scenes/01_cave.js（约 330 行）。最终性能：warm max 22ms / mean 21.1ms，cold（建缓存）在引擎 boot 时完成；确定性通过；0.2↔0.7s 运动差分 3.9% 像素。

管线

  1. 岩壁（全部缓存，cave_relief/cave_bg）
  2. 半分辨率 960×540 算高度场：fbm(x·0.0022,4oct)·1.0 + fbm(x·0.011,3oct)·0.16 + noise(x·0.05)·0.03（坐标用全分辨率像素）。
  3. 有限差分×52 得法线，光源 L=(-0.55,-0.62,0.56)（左上），shade = clamp(0.5+(dot-0.56)·0.9)；底色在 #ce925a(亮赭)/#6e4426(暗)/#b6643a(红斑) 之间用两层低频 fbm 混，再 ×(0.72+shade·0.55)。放大到全屏用平滑插值 → 起伏柔和。
  4. 叠两层 P.grain（暗 0.22 密度 α0.32、亮 0.10 α0.28）出颗粒；10 条随机游走裂缝（每步转角 ±0.45rad、步长 14–40px、12% 概率分叉），深线下面垫一条 +1.6px 偏移的亮线 → 刻痕感。
  5. 暗角：径向渐变 r 260→1180，外圈 α0.8；中心静态暖光用 lighter（α0.36）只照亮岩壁。
  6. 踩坑：relief 的中频项系数一大（0.35、×60 法线）整面墙就成了迷彩/沙丘，人物叠上贴图后像迷彩服。中频降到 0.16、法线 ×52 后才像岩面。
  7. 「颜料吃进岩石」
  8. 所有图形统一画法 shape()：先用 fuzz 图案（稀疏炭点，宽 2lw+7）描一遍 → 再用 ink 图案（炭黑、7% 随机孔洞 + 噪声 >0.58 处大孔，宽 2lw）描 → 最后平涂填色盖住内半圈。效果 = 实心炭线 + 喷点毛边，且 painter 顺序天然处理遮挡（手臂盖住外衣的线）。
  9. 炭笔「沸腾」：两张 256 图案每 1/9 s 用 pattern.setTransform 随机平移一次，几何不动、颗粒在跳，比抖动路径省且不变形。
  10. 整个颜料层画完后 source-atop 叠一张 cave_figtex：岩面阴影→黑 α(0.5-v)·150、亮处→暖白 α(v-0.5)·50、暗/亮颗粒、低频干湿斑 α≤70。颜料层只有一次全屏合成，所以 19ms。
  11. 填色都是不透明平涂，颜色靠贴图「脏」掉；不要用 multiply 叠颜料——白垩（猫的白）会消失。
  12. 负形手印/爪印：320² 临时画布高斯喷点（σ46·s 3200 点 α0.15–0.6 + σ28 1400 点），再 destination-out 一张实心手形蒙版，最后蒙版 α0.3 填 #f6e2bc。手形必须逐块 fill 到蒙版：把手掌椭圆和手指胶囊 addPath 进一个 Path2D 一次 fill，子路径绕向相反处 nonzero 抵消，出现缺口（r4 踩到）。
  13. 火光：每帧一层径向渐变，中心 (1000+40·noise(t·3.1), 540+26·noise(t·2.3))，强度 0.13+0.09·noise(t·8.5)+0.04·sin(21t)，用 overlay 合成（α=强度×2.6）。外圈再叠一层随火光反向呼吸的暗角。踩坑：一开始用 lighter，少女的金发和兽皮被洗成粉白、失去赭石饱和度，改 overlay 后颜色回来了。
  14. 余烬：P.particles 三组（左 0–360 ×11、右 1540–1920 ×12、中间 ×5），y 从 1110 漂到 120，life 5.5s；亮核 r 2.2–4.6 + 3.2 倍光晕，|sin(6t+1.9i)| 闪烁，sin(q·π) 首尾淡入淡出，lighter 合成。

02_egypt · 公元前1350年埃及墓室壁画（纯代码）

文件：scenes/02_egypt.js（约 460 行）。性能：warm max 20.7ms / mean 10.5ms（1920×1080），boot 时 init() 预热缓存，第一帧不再卡 170ms。确定性检查通过。

管线

  2. 会动的母题（每帧画，便宜）：水纹象形字流动、阿顿光线＋末端小手开合、两条长光线伸到猫面前托安卡、圣甲虫推日球。
  3. 角色：埃及程式重画，不走 RIG.drawGirl/drawCat，只取锚点与编舞。

埃及壁画是「无透视、平涂、轮廓线」，这里不用任何笔触渲染器，线条也不沸腾（干净的 2.2–2.8px 深棕线 #2a1810 才像），时代感全靠程式（侧脸正面眼、正面双肩）＋色板＋纹样密度。

踩到的坑

  • selfcheck 的 0.2↔0.7 差分在本段会「全画面都在动」——那是引擎的拍点冲击缩放（lt<0.36s），不是场景在动。看真实运动要比 lt≥0.4 的两帧。
  • P.texture 首次生成约 170ms；在 init() 里预热（引擎 boot 时调用），否则会卡在 T01 转场第一帧。
  • 原片 ref 里的碎石块是转场残留，不是画面内容，别照抄（设定稿里也没有）。
  • 年份牌区域 1500–1890×40–210 只留墙面；右侧象形栏从 y=252 开始正好避开。

核心思路：布局只算一次，颜色每帧流过石块

马赛克的动画应当长成这样：石块本身固定在墙上，动的是颜色从一块流到另一块。所以渲染器拆成两半。

  1. init（build()，206ms）：先算出每一块石头在哪、多大、朝哪、哪些像素属于它、斜面明暗如何，存成 ID（Int32，每像素对应的石块号，-1 表示灰浆）和 SH（Uint8，每像素明暗，128=1.0）。
  2. 每帧：重画平涂底稿，getImageData 一次，然后在动态石块的中心点取色（加上每块石头固定的颜色抖动），再在动态矩形里逐像素填 色×明暗>>7，最后 putImageData 到自己的离屏画布，用 drawImage 贴到 c 上。
  3. 坑：不能直接对 c 做 putImageData，因为它会无视引擎的镜头冲击缩放（punch zoom）和转场裁剪。必须先写进离屏画布再 drawImage。
  4. 每帧逐像素只处理约 100 万像素（4 条边框带、画框内、少女、猫），用 JS 循环大约 5ms。所有离屏 context 都用 {willReadFrequently:true}，getImageData 才快。

按 Hausner 2001「Simulating Decorative Mosaics」的思路简化而来。

  • 结构图：静态底稿加上第 0 帧的猫和少女（不画会动的近侧手臂），降采样到 960×540。相邻像素的 RGB 差之和大于 34 就记为边缘，再把类别图里边框带的边界也算作边缘。
  • 距离场：用 Felzenszwalb–Huttenlocher 精确欧氏距离变换（两遍一维下包络），半分辨率下约 20ms。
  • 沿轮廓走线放石块：候选像素满足 |d−(k+½)s|<1.5、k<该类的圈数，也就是距离场的等值线带。从未访问的候选点出发，沿 8 邻域优先走「和上一步方向最一致」的候选（方向做 0.6/0.4 平滑），离上一块的距离 ≥s 时放一块。石块的朝向取距离场梯度的切向。空间哈希保证任意两块的间距 ≥0.8×平均尺寸。

石块形状与灰浆：加权 L∞ Voronoi

  • 每块石头是一个旋转方块。四条半边长各自独立取 s/2×(1.08–1.28)，旋转角再抖动 ±0.06rad。像素到石块 k 的距离定义为 D=max(|u|/h±, |v|/h±)，其中 (u,v) 是像素在该石块局部坐标里的位置。
  • 光栅化时对每个像素记录最小的 D1、次小的 D2 和对应石块号，开销是每块石头的包围盒 1.5h。
  • 灰浆：满足 D1>1，或 (D2−D1)·h/2 < g（g = clamp(0.1s, 0.75, 1.25)px）的像素算灰浆，也就是落在两块石头的平分线附近。所以缝宽约 1.5–2.5px，石头被邻居「切」出不规则边，像真的錾过。

毛笔 brush(c, pts, {w, tone, dry, reveal, bristles, head, tail}) - 点列先 Catmull-Rom 加密，再按 4px 等弧长重采样（KIT.resample）。不重采样的话，飞白噪声的频率会随笔画长短变化。 - 笔压：prof(q) = smoothstep(0,head,q) · (1−0.7·smoothstep(1−tail,1,q)) · (0.85+0.15·noise)。 - 湿笔芯：整笔都用 ribbon 填，宽度 w·prof·(1−0.85·dry·q^0.8)，α 为 tone×0.72。越往后越细，表示墨在用完。 - 笔毛：每根一条连续折线，横向偏移 ±0.475w·prof。噪声 noise(k·1.9, i·0.09) 低于 dry·q^1.2·0.95+0.05 时断开，露出的纸就是飞白。 - 坑：第一版按「每一小段单独 stroke＋round cap」画笔毛，接头处叠出一节节深点，看起来像竹节或麻绳。必须改成每根笔毛一条连续 path、butt cap。 - 参数：窗框 w14–18、dry .45–.6；案面 w22；衣纹 w4–6、dry .3–.4、tone .78；地线 w5、dry .85、tone .35。

晕染层 washLayer - 形状先画在 scratch 上，再用 multiply 合到纸上，分两遍。 - 外晕：blur(halo·(0.4+grow))，α 为 haloA·grow。 - 本体：blur(blur·(1.6−0.6grow))。 - grow 按 lt 从 0 走到 1：开场是从无到有洇开，之后外晕继续慢慢变宽，这就是「墨在纸上晕开」。 - 少女 halo 12、α.6；猫 halo 9、α.78；远山 halo 14。

留白 - 猫的白色部分（口鼻、胸、爪）用 destination-out 从赭石层里挖掉，露出纸色。这比画白色更有水墨味。 - 少女的交领内衫也这样挖掉。 - 面部用纸色填，再用 1.8px 焦墨白描勾。

色 - 墨 [16,14,12]，用 tone 分出五色（焦 .9／浓 .8／重 .6／淡 .35／清 .15）。 - 赭石（猫）#c47a3c；花青（衣）#6f8aa0、广袖 #7d97ab；藤黄（金发）rgba(226,170,52,.75) multiply。 - 胭脂红只点三处：腰带、发簪珠、点唇，用 [190,40,40]。另有朱日 #d8553f、钤印 #c4281e。

母题动画 - 开场写出：lt 0→0.45，每笔 reveal = ss(d, d+l, lt/0.45)，按窗、案、竹、猫、人的顺序依次写出。 - 竹：分节淡墨主枝，绕 (835,70) 摆 sin(2.9t)·0.11，越往枝梢越大。5 组个字叶各 3 片（L110、w15），翻动 sin(7t+g)·0.2。 - 雾带：4 条纸色椭圆，blur 14、α.72，以 150–270px/s 横移，远山时隐时现。 - 八大式小鸟：从窗右侧以 420px/s 掠过，翅膀两笔，每秒约扇 8 次（sin(52·lt)）。 - 齐白石虾（挂轴里两只，1.45 倍）：6 节淡墨节＋头胸甲中间一笔焦墨，两长两短须做行波，三节长钳，身体弯曲 sin(7t)·0.12，沿曲线游动。 - 八大白眼：猫的瞳点顶到眼眶上方，「白眼向天」。 - 钤印：lt 0.3–0.4 从 1.5 倍压到 1 倍，multiply 盖上；白文「白石」。

坑 - 静态笔触在写出期间实时画，写完一次性缓存成 ink_static，否则每帧要画几千根笔毛。 - 小鸟第一版的路径穿过竹叶丛，看不见，改到雾带上方 y≈470 才读得出来。 - 晕染用的是 multiply，透明，所以窗台墨线会透过猫的耳朵，桌腿会透过裙子，审片读成「层级错了」。修法是在猫和衣裙的剪影里先补一层纸色（clip 后 drawImage 纸），再上晕染。这等于在纸上「先留出这块地方」。
