14_8bit · 1985 8-bit 像素游戏

管线

  1. 整幅在 240×135 低分辨率画布上画（1 低像素 = 8 屏幕像素，原片实测像素块就是 8px），最后 imageSmoothingEnabled=false 一次性 drawImage 放大 8 倍。
  2. 背景逐像素 fillRect（缓存 8b_bg）：十字点纹墙＝6px 网格、隔行错 3px 的 3×3 十字；木地板条 y=106–113，每 24px 一道黑缝；砖块 16×6＋1px 缝，隔行错 8，上沿和左沿一行米色高光（#fbe2a6）。窗里天空用 3 档蓝（#0856ef / #47c4f8 / #aae9fb），交界 ±0.05 的带子做 (x+y)%2 棋盘抖动——这是 NES 做渐变的唯一办法。
  3. 角色＝RIG 路径缩到低分辨率填色 → spriteize：每个部件单独一层（远侧手臂 / 身体腿 / 头发 / 脸 / 刘海 / 近侧手臂；猫身 / 猫头），每层：
  4. getImageData → alpha < 110 直接透明（去抗锯齿）→ 其余量化到 14 色角色调色板（最近色）；
  5. 外轮廓描 1px 黑边（透明像素的 4 邻域里有不透明像素就涂黑）。 分层描边是关键：只描一次整体外轮廓时，头发/脸/手臂糊成一块；每个部件单独描边才有 NES 精灵那种内轮廓。
  6. 五官全部逐像素点（眼 1×2 黑＋眉，猫眼 2×2 黑＋左上 1 白高光，粉鼻 1px，腮红 2×1），用 RIG 锚点 /8 取整定位。
  7. 马克杯不用 RIG.drawCup：AA 路径缩到 6px 宽会糊，直接在低分辨率上画 6×5 白杯＋两道红条＋3px 把手，跟着 G.cup 走。
  8. HUD 在全分辨率画：PressStart2P 48px（字体 1 像素 = 6 屏幕像素，64px 太宽会让 WORLD 1-1 撞上苹果图标），8px 黑投影；猫头/心/苹果图标是字符串位图，每格 8×8。

牛仔裤

RIG.girl 是长裙，8-bit 版用两段 RIG.taper（髋 G.hipSeat→膝 (1222,724)→踝 (1214,872)，宽 92/76/56）画蓝裤，远侧腿深一档 #0838a8 错后 26px；白球鞋＋一道红条。

小循环（片中只停约 0.23s ≈ 11 可见帧，全部做成步进动画）

  • 猫尾：15fps 四姿态循环 [-0.55, 0, 0.55, 0]（RIG.cat 的 tail 参数），像素动画的「几张图交替」。
  • HUD 心闪：lt 0.16–0.23（≈ 630 帧）每 2 帧一换：满心变白、空心变满红。
  • 盆栽抖：同一窗口里叶子整像素 [0,1,0,-1] 偏移。
  • 问号块顶出金币：lt 0.06–0.22 半正弦上 9px 再落回。
  • 窗外云 2 帧左移 1px；像素热气三列 1×2 点、30fps 每帧上移 1px、6px 循环。

踩到的坑

  • RIG 猫头顶到 y≈535，会压住窗台（窗到 y=590）。这是共用骨架的位置，没挪；8-bit 黑描边让重叠更显眼，但转场依赖标准构图，保留。
  • spriteize 读的是非预乘 RGBA，别再除 alpha。
  • 性能：热帧 2.5–6ms，冷启动 11ms。

15_raytrace · 1993 早期光线追踪 CGI

不用 3D 引擎，靠 2D Canvas 的「着色约定」假装是渲染器出图。

塑料着色（每个部件都过一遍）

plastic(c, path, base, hx, hy, R)： 1. 底色填充； 2. 以高光点 (hx,hy) 为心、半径 R 的径向渐变：0→白 .55，0.28→白 .06，0.62→透明，1→深紫 rgba(10,0,30,.42)（边缘压暗＝体积）； 3. 环境反光：lighter 叠一圈 rgba(70,150,150,.28) 的描边，宽 0.18R，向左偏 0.04R——墙是青绿色，反光就是青绿色； 4. 一颗硬边白色椭圆镜面高光（0.16R × 0.09R，透明度 .85）。这一笔最像 90 年代 Phong。

肢体用 cyl()：渐变横跨肢体法线方向（暗 .25 → 白 .5 窄带在 22% 处 → 暗 .45），再沿 20%–75% 画一道白色细高光线。 少女用 RIG.girl 的 Path2D（长发），裙子换成蓝色塑料圆柱腿＋膝盖球关节，肩膀加球关节——就是「玩具人偶」的关节感。 RIG 的猫身是折线，塑料感会露出棱角：先 RIG.smooth(K.bodyPts) 再着色。虎斑用 filter: blur(2px) 画成「印在塑料下面」的软条纹。

场景

  • 墙：径向渐变 #7dbcb9 → #64a6a6 → #3f8285，光源在窗的位置；窗的投影 blur(10px) 偏右下。
  • 窗外：粉紫渐变天（#a24cc4 → #df62ae → #f5a08a → #f8c070），两层山，山体上叠 28×26 的粉色线框网格（早期 CG 的 wireframe 地形），雪顶是锯齿三角。
  • 地面：逐像素透视棋盘，消失点 (960,480)，X=(x-960)/dy, Z=1/dy，格子 TX=0.27、TZ=0.00029，2×2 超采样抗锯齿，近墙 140px 内加 35% 雾。缓存，冷启动整场 53ms。
  • 反射：物体层（椅/桌/少女/猫）画在离屏层，translate(0, 2*906); scale(1,-1) 镜像、globalAlpha .34 画进地面裁剪区；道具各按自己的接地线镜像（锥 780、紫环 846、铬球 800），并先画到独立层再整体半透明——否则紫环的 140 颗小球各自 .34 叠加会变成不透明。
  • 玻璃桌：半透明绿椭圆＋厚边＋白描边，一条斜向反光每秒滑 260px。

小循环（0.23s 内要看得见）

  • 紫环：140 颗球沿圆环排布，绕竖轴以 7 rad/s 自转、倾斜 0.35，按深度排序画（先一层暗紫底让球连成管，再逐颗径向高光）。0.23s 转 1.6 rad，从正面转到侧面，非常明显。
  • 铬球：每帧逐像素环境映射（反射向量向下→棋盘，向上→粉紫天＋一条窗光），棋盘 u 坐标随 t*4.5 平移＝在转；菲涅尔边缘提亮。直径 104px，每帧 <2ms。
  • 镜头光晕（lighter）：日芯辉光 170px 以 23 rad/s 脉动 ±8%；12 道星芒以 1.6 rad/s 旋转；水平长条光 960px；5 个鬼影（圆＋六边形）沿「太阳→画面中心」直线排布、随 sin(t*5)*0.03 滑动。
  • 猫眼绿光：lighter 径向渐变半径 46px，以 18 rad/s 脉动 ±25%。
  • 端杯（choreo.cup）、甩尾、眨眼、热气照常。

坑

  • 转场 wireframe 用新画面第一次出现时的帧算边缘并缓存（once('edges')），所以 lt≈0 那一帧要完整——别在 lt=0 留空白或淡入。
  • 性能：热帧 23ms，冷启动 53ms。

26_vaporwave · 2011 蒸汽波 / 赛博霓虹

来源：迁移测试 B（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 scripts/engine/scenes/26_vaporwave.js。

实验时的文件名：scenes/c5_vaporwave.js（约 210 行）。审片红灯：上衣第一版是粉色，和粉调肤色混成一片，读起来像没穿衣服。改成薰衣草紫风衣 #8f7cf6＋白三角领＋青色拉链线。每帧中位 49ms；帧差 25%（VHS 后期让全屏都在动）。

管线：整幅先画进离屏 S，再做 VHS 后期输出到 c（计数器由引擎画在最上层，不受色差影响）。 1. 墙：深紫纵向渐变 #0d0322 → #4a0f6a ＋ 窗口处洋红径向光、招牌处青色径向光。墙脚一条青色灯带。 2. glowLine(c, col, w, blur)：同一路径先用 shadowBlur 描粗的辉光，再描 2–3px 近白芯线，就是霓虹灯管。 3. 窗里落日：太阳是黄 → 橙 → 洋红竖向渐变，用 destination-out 切 7 条横缝，缝宽随深度变大（2 + q²·16），整体以 0.9/s 上移。地平线是线框山（洋红辉光），下面是青色透视网格往观众方向滚，左右棕榈剪影摇。 4. 地面：洋红透视网格，消失点 (960,600)，横线 y = 600 + 520/d、d = k + 1 − phase（phase = 1.3t mod 1），线宽随近处加粗。 5. 霓虹招牌「カフェ」用折线自己画灯管（不依赖字体）：每个假名 1–3 笔，(u,v) 单位坐标。逐字按帧哈希闪：hash(floor(30t), k) < 0.07 灭；「フ」额外在 f mod 17 < 5 时 22% 概率灭，灭时画暗紫灯管。 6. Win95 对话框 TEA.EXE：灰体、海军蓝渐变标题栏、进度块 3 + 14lt 格、百分比 18 + 70lt。桌上大理石胸像（侧脸剪影 22 点、紫灰渐变＋静脉线＋粉色轮廓光＋墨镜梗）。 7. 角色：粉毛衣、青色百褶长裙、金发＋粉发圈。辉光轮廓「朝窗一侧粉、背面青」：同一组路径描两次，分别 clip 在左右半屏。

VHS 后期 vhs(c, S, t, lt) - RGB 分离：对每个通道，把 S 画进临时画布、multiply 纯色 #ff0000/#00ff00/#0000ff 取出单通道，再以 lighter 错位合成到黑底。错位量 3 + 1.5sin(7t)，偶发（hash<0.12）+6。 - 跟踪噪声带：70px 高，(520lt + 200) mod (H+160) 下滚。带内每 6px 一条横向错位 ±30·sin(πy/bh)，叠 90 条白灰噪线。 - 扫描线：4×4 tile pattern（第 0 行 α 0.28、第 2 行 α 0.12）。OSD：PressStart2P「PLAY」＋手画 ▶（字体里没有这个字形），16 帧一闪；左下日期、时间码按 lt 走。

色板：洋红 #ff4fd8、热粉 #ff2f8f、青 #3ff6ff、深紫 #12052a / #2a0b4a、日黄 #ffd84a、橙 #ff8a3a。

坑 - 全角「ＶＡＰＯＲＷＡＶＥ」、▶、日文在 lib/fonts 里都没有，会静默回退系统字体。标签改用半角＋字距 7，▶ 和假名都自己画。 - 人物描边用的是部件路径，腰线、手臂和躯干的交界也会发光。霓虹线稿能接受，但想要纯外轮廓，得先把剪影画进离屏，再描离屏的边缘。
