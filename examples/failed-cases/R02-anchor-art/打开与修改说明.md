# 价签之外 · 60秒样片

先打开 `watch.html` 看无音轨版本，页面默认暂停。无需渲染即可直接打开 `out/anchor-silent.mp4`。`out/anchor.mp4` 是带配音、原创配乐和动作音效的版本，不会自动打开。

## 本轮结果

- 60秒、9:16、1080×1920、30fps，1800帧。
- 内容来自凯撒的复利实验室《一招破解：锚定效应》，本次只改编“最初价格成为判断参照”这一条主线。
- 画风参考 weilanx-claude-videos 的新艺术运动配方，使用原创插画素材与确定性代码动画。
- 旧样片保留在相邻的 content-lab-20261021 等历史目录。

## 可编辑文件

- `film.mjs`：镜头、对象状态、构图、字幕；`art.mjs`：标签、植物曲线、插画摆动。
- `assets/shop.png`、`shopper.png`、`coat.png`：3张原创图像素材。
- `assets/timeline-anchor.json`：实际字幕时轴；`source/scripts.json`：完整改编文稿。
- `music.mjs`：原创配乐和音效落点。独立声轨位于 assets 下的 voice-mix、music-original、sound-design.wav。
- `out/anchor.srt`：28条字幕，与整段配音实际词边界对齐。
- `out/premiere.xml`：FCP7 XML，9段可剪切画面和3条独立音轨。动画细部仍在代码中修改；XML未在 Premiere 中实际导入验证。移动目录后按提示重新定位媒体，字幕需另行导入。

## 修改与重新导出

依赖：Node.js、Chrome、FFmpeg、Python 3。Python 工具需要 Pillow、OpenCV、numpy；只有重新生成配音才需要 edge-tts 和网络。渲染使用 puppeteer-core，可优先复用本机历史缓存或通过 npm 安装 package.json 中的依赖。

在项目目录执行 `node render.mjs full` 导出60秒无声画面。局部测试可用 `node render.mjs clip 36 46`；截图可用 `node render.mjs probe 4.8,17.4,43.4,56`。OUT_WIDTH 和 SUBFRAMES 环境变量分别控制输出宽度和采样数，正式版为1080与3。

已有配音无需重做。需要修改文案时执行 `python prepare_audio.py` 后检查时轴，并在 `film.mjs` 更新按句匹配的动作。不要运行 setup_project.py，它仅保留为初始搭建记录。

运行 `run.ps1` 可用缓存配音、当前画面和当前文稿重建配乐、混音、视频并完成技术检查；不会外放。最后运行 `python package.py` 更新交付压缩包。
