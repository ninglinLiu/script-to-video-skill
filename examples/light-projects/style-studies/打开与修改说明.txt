修改入口：
style-editorial.mjs：图形排版、九格变成眼睛、观察视野展开。
style-spatial.mjs：Three.js 几何、材质、镜头路径、研究镜与结构展开。
style-pixel.mjs：人物走位、半身/小人切换、搭建、放大镜、书本。
common.mjs：绘图函数和共同字幕。
assets/timeline.json：复用的真实旁白时间和字幕。
mix_audio.py：离线声音构建，不调用音频设备。
render.mjs：复用 Poisson / 上一版的确定性渲染器，已加 --mute-audio。
run.ps1：重渲三版，合成正常配音版和无声版，输出质检图与结果。

本机运行：
powershell -ExecutionPolicy Bypass -File .\run.ps1
Python / Node / Chrome / Puppeteer 沿用本机现有路径；异机需要改 render.mjs 与 run.ps1 的运行时路径。FFmpeg 和 ffprobe 需要在 PATH。
浏览器 preview 若限制本地模块，使用 Python http.server 服务本目录；成片 watch.html 直接打开即可。
