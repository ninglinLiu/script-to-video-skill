# 三个半分钟内容试样

双击 `watch.html` 查看。页面只引用无音轨 MP4，默认暂停；带旁白、配乐和音效版本通过下载链接单独保存。

每条为 1080×1920、30 fps、30 秒。`out/*-silent.mp4` 是无音轨版；`out/editorial.mp4`、`spatial.mp4`、`pixel.mp4` 是配音版；同名 SRT 由整段配音的实际 WordBoundary 时间生成。`out/compare-silent.mp4` 是三屏同步对照。

## 内容与编辑入口

从用户提供的两篇完整公众号文章重新选段，不是另外获取了三篇新文章。锚定取自《一招破解：锚定效应》；购买力、重复利用工具取自《两个同样勤奋的人，为何十年后差100倍？》。各片是原创场景改编，完整文本、逐条来源映射及事实核对在 `source/`。

- 改文案：`source/scripts.json`；重新运行 `prepare_audio.py` 生成整段语音和实际时间戳。
- 改画面与动作：`style-editorial.mjs`、`style-spatial.mjs`、`style-pixel.mjs`。
- 改字幕与统一版式：`main.mjs`、`common.mjs`、`index.html`。
- 三维模型、光照与镜头在 `style-spatial.mjs`；像素 PNG 动作图集和肖像在 `assets/sprites/`、`assets/bust/`。
- 声音与成片检查：`finish.py`。仅离线编码，不打开音频设备。

可编辑的是代码动画工程，未冒充剪映、PR、FCP 原生项目。本轮为选题与风格短样，不包含截图背景要求中的 60–90 秒短片和 8–10 分钟长片。

## 本机重新导出

在项目目录执行 `./run.ps1`。依赖本机现有 Python 3.11、Node.js、Chrome、ffmpeg / ffprobe，以及历史 Puppeteer 缓存路径。Puppeteer 路径在 `render.mjs` 的 `createRequire`，迁移电脑时改为对应安装位置。未封装跨设备环境安装器。

渲染沿用《泊松过程》到旧样片的逐帧链；本工程使用 `node render.mjs clip 0 30`。不要使用历史 `full` 分支。`bootstrap.py` 仅留作初次拷贝过程记录，不要再次运行覆盖已修改文件。

局部验证示例（PowerShell）：

```powershell
$env:STYLE='pixel'
$env:OUT_WIDTH='540'
$env:SUBFRAMES='1'
node render.mjs probe '1.2,5,11.5,15,22,27'
$env:FILM_OUTPUT='qa/pixel-review.mp4'
node render.mjs clip 10 23
```

正式版本每帧取 3 个子帧样本，30 秒共 900 帧。配音率分别为 +3%、+8%、+6%；所有声音仅写入文件。字幕和动作读取真实配音时间，不能通过改字幕起止来掩盖语音差异。

## 验证记录

`qa/final-checks.json` 为分辨率、时长、帧数、完整解码、音轨和离线响度检查。`qa/*-final-sheet.jpg` 为手机宽度抽帧，`qa/*-continuous-*.jpg` 为关键转场连续帧；`qa/制作方审看.md` 记录发现与修正。

技术检查不替代审美认可。用户要求不外放，本轮未做听感验收；内容和观感由用户选样后再决定扩写。
